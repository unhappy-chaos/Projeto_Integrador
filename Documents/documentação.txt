DOCUMENTO DE ESPECIFICAÇÃO DE REQUISITOS
Sistema de Gerenciamento de Frotas

Tipo de aplicação: Desktop
 Banco de Dados: MySQL
 Segmento: Empresa de Transporte
 Versão: 1.0

1. Introdução

O Sistema de Gerenciamento de Frotas tem como objetivo auxiliar uma empresa de transporte no gerenciamento das informações relacionadas à sua operação.

O sistema foi desenvolvido utilizando banco de dados MySQL e permite armazenar dados sobre funcionários, motoristas, veículos, cidades, rotas, viagens, manutenções e abastecimentos.

Nesta versão do projeto, o foco principal está na modelagem e implementação do banco de dados, garantindo o correto relacionamento entre as entidades e a integridade das informações armazenadas.

2. Objetivo Geral

Desenvolver um sistema capaz de armazenar, organizar e relacionar informações de uma empresa de transporte, possibilitando o gerenciamento eficiente da frota e de suas operações.

3. Objetivos Específicos
Cadastrar funcionários da empresa.
Cadastrar motoristas.
Cadastrar veículos da frota.
Gerenciar cidades e rotas.
Registrar viagens realizadas.
Registrar manutenções dos veículos.
Registrar abastecimentos.
Garantir a integridade dos dados através dos relacionamentos entre tabelas.
Centralizar as informações da empresa em um único banco de dados.
4. Escopo do Sistema

O sistema contempla os seguintes módulos:

Módulo	Funcionalidade
Funcionários	Cadastro de funcionários

RN009	Toda manutenção deverá estar vinculada a um veículo existente.
RN010	Todo abastecimento deverá estar vinculado a um veículo existente.
RN011	Valores de abastecimento e manutenção não poderão ser negativos.

12. Casos de Uso
UC001 – Cadastrar Veículo

Ator: Funcionário

Objetivo: Registrar um novo veículo na frota.

Fluxo Principal:

O usuário acessa o cadastro de veículos.
Informa os dados do veículo.
O sistema valida os dados.
O sistema verifica se a placa já existe.
O sistema salva as informações.
O sistema confirma o cadastro.

Fluxo Alternativo:

Caso a placa já esteja cadastrada, o sistema deverá exibir uma mensagem de erro.
UC002 – Registrar Viagem

Ator: Funcionário

Objetivo: Registrar uma nova viagem.

Fluxo Principal:

O usuário acessa o módulo de viagens.
Seleciona um motorista.
Seleciona um veículo.
Seleciona uma rota.
Informa a data da viagem.
O sistema registra a viagem.
13. Critérios de Aceitação
Cadastro de Veículos
Todos os dados obrigatórios devem ser informados.
A placa não poderá estar cadastrada anteriormente.
O registro deverá ser salvo corretamente no banco.
Cadastro de Viagens
Deve ser possível selecionar motorista.
Deve ser possível selecionar veículo.
Deve ser possível selecionar rota.
A viagem deverá ser armazenada corretamente.
Cadastro de Abastecimentos
Deve permitir informar veículo.
Deve permitir informar litros abastecidos.
Deve permitir informar valor total.
Deve permitir informar o posto de abastecimento.
14. Limitações e Restrições
O banco de dados utilizado é MySQL.
O projeto está focado na estrutura do banco de dados.
Ainda não possui interface gráfica integrada ao banco de dados.
Não possui níveis de acesso implementados.
Não possui controle de permissões.
Não possui rastreamento GPS.
Não possui controle de cargas.
15. Considerações Finais

O Sistema de Gerenciamento de Frotas foi desenvolvido com o objetivo de centralizar e organizar as informações relacionadas à operação de transporte de uma empresa.

A estrutura atual do banco de dados permite o gerenciamento de funcionários, motoristas, veículos, cidades, rotas, viagens, manutenções e abastecimentos, servindo como base para futuras implementações, como interface gráfica em CTkinter, autenticação de usuários e funcionalidades adicionais para aperfeiçoar o gerenciamento da frota.
